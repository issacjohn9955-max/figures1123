# 复现指南

本仓库里**能逐位复现的只有项目图 24–27**（`code/render_current.py` + `inputs/` 冻结表 + `style/` 样式快照）。
01–23 是既有工作流图集，只保留成图；`code/build_library.py` 是发布者在原工作区组装合订本用的脚本，依赖其本地目录结构，仓库内仅作存档。

## 1. 环境

| 项 | 要求 |
|---|---|
| Python | 3.9 及以上 |
| 必需库 | `numpy`、`matplotlib` |
| 可选库 | `pandas`（个别数据整理路径使用） |
| 中文字体 | 默认使用 `style/theme.json` 里指定的无衬线族；缺字体时 matplotlib 会回退，可能影响字形但不影响数值 |
| 底图 | `inputs/world_countries_110m.geojson`（Natural Earth 1:110m），已随包提供 |

安装：

```bash
python3 -m pip install numpy matplotlib pandas
```

## 2. 一条命令重绘

```bash
cd SV_figure_library_20261122
python3 code/render_current.py
```

默认行为：

- 读取 `inputs/`（冻结表与底图）
- 读取 `style/theme.json`、`style/palettes.json`（配色与排版）
- 输出到 `figures/`：`24_*.png`（600 dpi）+ `24_*.pdf`（文字与线条可编辑），其余三张同理
- 终端逐张打印 `Rendered 24_origin_world_asia` 之类的进度

## 3. 参数

| 参数 | 默认 | 说明 |
|---|---|---|
| `--inputs` | `<包>/inputs` | 冻结输入表目录 |
| `--output` | `<包>/figures` | 输出目录 |
| `--style` | `<包>/style` | 主题与配色快照 |
| `--run` | 无 | 一套已完成队列结果的目录；给出时会先做归一化 |
| `--evidence-tables` | 无 | 跨方法证据表；与 `--run` 搭配 |
| `--basemap` | 无 | 底图 geojson；与 `--run` 搭配 |

替换研究结果：

```bash
python3 code/render_current.py \
  --run /path/to/completed_run \
  --evidence-tables /path/to/evidence.tsv \
  --basemap /path/to/world_countries_110m.geojson \
  --inputs inputs --output out
```

只换输入、不改代码：

```bash
python3 code/render_current.py --inputs /path/to/new_inputs --output /path/to/out
```

## 6. 校验

重绘后若想确认与发布版本一致，可比对 `MANIFEST.tsv` 中对应文件的 sha256：

```bash
cd SV_figure_library_20261122
shasum -a 256 figures/24_origin_world_asia.pdf
grep 'figures/24_origin_world_asia.pdf' MANIFEST.tsv
```

注意：**PDF 的字节不保证稳定**（不同 matplotlib 版本可能写入不同的创建时间或字体子集），PNG 的像素比 PDF 字节更适合做一致性判断。

## 7. 常见问题

| 现象 | 原因与处理 |
|---|---|
| `ModuleNotFoundError: matplotlib` | 未装依赖，`pip install numpy matplotlib` |
| 图内中文变成方块 | 系统缺中文字体；装一个无衬线中文字体，或在 `style/theme.json` 里换 `font.family` |
| 输出目录为空 | `--output` 指向的目录不存在时不会被创建，先 `mkdir -p` |
| `--run` 报错 | `--run` 必须同时给 `--evidence-tables` 与 `--basemap` |
| 重绘结果与发布版差一点 | 先确认 `inputs/` 未被改动；再检查 matplotlib 版本差异导致的排版微移 |
| 想重画 01–23 | 仓库内只有成图，不含上游分析脚本；需要回到原始分析工作区 |
