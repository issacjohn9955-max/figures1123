# 图册导读

这份文档讲清楚三件事：**49 页怎么排的**、**编号怎么对应文件**、**翻到某一页时该看什么**。

## 1. 整体结构

合订本 `SV_figure_library.pdf` 共 49 页，按"索引 → 项目图 → 索引 → 参照图"的顺序排：

| 页 | 内容 |
|---|---|
| 1 | 项目图索引：编号 01–27、标题、页码 |
| 2 | 项目图说明 / 图例约定（视发布版本） |
| 3–25 | 项目图 01–23（既有工作流图集） |
| 26–29 | 项目图 24–27（本轮重绘） |
| 30 | 参照图索引：编号 F01–F19、模块、页码 |
| 31–49 | 参照图 F01–F19 |

页码与文件的对应关系不需要手抄，`figure_library_catalog.tsv` 的 `gallery_page` 字段就是页码，`file` 字段是包内相对路径。

## 2. 两套编号

| 前缀 | 含义 | 数量 | 位置 |
|---|---|---|---|
| `01`–`27` | 项目图（本项目的图） | 27 | `baseline/`（01–23）、`figures/`（24–27） |
| `F01`–`F19` | 参照图（借版式用的英文图） | 19 | `references/` |

两套编号互不重叠，检索时先看前缀即可判断性质：**项目图回答本项目的问题，参照图只提供版式与坐标轴写法**。

## 3. 项目图分组速查

| 组 | 编号 | 主题 | 数据性质 |
|---|---|---|---|
| A | 01–04 | 跨方法证据、原产地、候选重叠、结构与地理校正的敏感性 | 实测 |
| B | 05–08 | 单环境 vs 联合 LFMM、区域关联与 LD、外部验证、配对预测 | 合成/版式 |
| C | 09–11 | 采样规模、环境相关与共线性、SV 背景结构（PCA） | 实测 |
| D | 12–16 | 全基因组偏秩扫描、候选位点、RDA 轴检验、LFMM2 的 K 敏感性、QQ 诊断 | 实测 |
| E | 17–20 | 基因型可检测性、联合 Manhattan、局部 SV–BIO3、气候范围 | 实测 |
| F | 21–23 | 模型比较、留出预测与增量误差、五模型指标 | 合成/版式 |
| G | 24–27 | 原产地、偏 RDA、跨方法汇总、配对统计 | 实测（本轮重绘） |

组 B 和组 F 共 7 张是版式示意，看到的坐标、P 值、计数**不可当作结果**——这一点在[数据与口径](数据与口径.md)里有逐条说明。

## 4. 24–27 这四张看什么

这四张是发布时用当前队列结果重绘的，也是本仓库唯一可以逐位复现的部分：

- **24 原产地分布**：当前主队列 405 个个体的 25 个代表性原产地坐标组；亚洲面板只画其中 21 组。看点在世界面板与亚洲放大面板的对应关系，以及哪些组落在同一个气候带。
- **25 偏 RDA 排序**：组坐标、环境箭头、轴惯量、BH 校正后的轴检验放在同一页。看图时先读轴惯量（解释了多少），再读箭头方向（环境梯度），最后看轴检验是否显著。
- **26 跨方法证据**：偏秩相关、LFMM2、偏 RDA 三种方法的发现数、检验分母、跨方法交集。**分母比发现数更重要**——不同方法的可检验位点数不同，直接比条长会误读。
- **27 配对统计**：同一 SV 等位位点上，偏秩相关与 LFMM2（K=10）的统计量配对比较，每个环境 52,991 个完整匹配。主图用分箱计数展示两个统计量的联合分布；BIO3 上的菱形标出通过偏秩相关 q<0.05 的位点。

## 5. 参照图怎么用

参照图的正确用法是**看结构，不看数**：

1. 先读 `figure_sources.tsv` 的 `provenance` 列——"Historical cohort" 表示历史队列，"Synthetic layout" 表示合成版式。
2. 再看 `condition` 列——那列写的是"什么条件下才能正式用"，例如"需要同一批个体的 SNP 与 SV 配对数据"、"需要匹配的 WorldClim 栅格"。
3. 需要正式使用时，按 `source` 列的固定提交链接回到来源模块，用当前队列重画。

## 6. 常见误读

| 误读 | 实际情况 |
|---|---|
| "图册里的数字都是本项目的" | 27 张项目图中 7 张是示意；19 张参照图的数字属于来源研究或历史队列 |
| "参照图可以直接放进论文" | 参照图是版式参照，正式使用要按 condition 列替换为当前队列结果 |
| "01–23 也能复现" | 01–23 是既有工作流图集，只保留成图，上游分析脚本与原始数据不在本仓库 |
| "页数 = 图数" | 49 页 = 27 张项目图 + 19 张参照图 + 3 页索引 |
